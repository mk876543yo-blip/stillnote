# Security policy

Stillnote stores notes and attachments in the browser or desktop profile on the user's device. Do not include real notes, workspace backups, credentials, or personal data in security reports.

## Reporting a vulnerability

Please report security issues privately through the repository's **Security** tab using **Report a vulnerability**. If private vulnerability reporting is unavailable, contact the maintainer through their GitHub profile before sharing details publicly. Please include the affected version, operating system, and concise steps to reproduce the issue.

The project is maintained by volunteers and does not provide a guaranteed response time. The latest source and release packages are available from [GitHub Releases](https://github.com/mk876543yo-blip/stillnote/releases).
